## The publish-contract check

| Assertion | Level |
|---|---|
| `type === "module"` | shape |
| `exports` is an object with a `"."` entry and a `"./package.json"` entry | shape |
| `files` is a non-empty array | shape |
| every `bin` value is a relative path with no `./` prefix and no leading `/` | shape |
| `engines.node` is set and contains no `<` | shape |
| `scripts.prepublishOnly` is set and mentions `check:all` | shape |
| `name` is scoped (`@scope/name`) | shape |
| every `files` entry exists on disk | `--exists` |
| every `bin` path exists on disk | `--exists` |

Exit 1 with every failed assertion listed; exit 0 silently otherwise.

## `smoke:pack` sequence

1. Plant `.env` (`SMOKE_DECOY=1`) in the package root if absent; remember whether we
   planted it.
2. `npm pack --json --pack-destination <tmp>` → tarball path and its file list.
3. Assert `.env` is not in the file list; assert every `files` entry that exists on disk
   is represented.
4. Create `<tmp>/consumer` with a minimal `package.json` (`type: module`);
   `npm install <tarball> --no-audit --no-fund`.
5. `node -e 'import("<name>")'` from the consumer succeeds and the export is a function
   named `hello` (or, generically, the module has at least one export).
6. If the package has `bin`: assert `<consumer>/node_modules/.bin/<key>` exists and runs.
7. Remove the planted `.env`; remove `<tmp>`.

## `smoke:registry` sequence

1. Pick a free port; write a Verdaccio config in `<tmp>` (`storage: <tmp>/storage`,
   `packages: '@snackbyte/*': { access: $all, publish: $anonymous }`, no uplinks,
   no self-registration).
2. `npx --yes verdaccio@6 --config <cfg> --listen <port>`; poll `GET /-/ping` until up.
3. Write project-local `.npmrc`: `registry=http://localhost:<port>/` and
   `//localhost:<port>/:_authToken=smoke`.
4. `npm publish --access public` (runs `prepublishOnly`, i.e. the real gate).
5. `<tmp>/consumer`: `npm install <name> --registry http://localhost:<port>/`; import;
   run `bin` if present.
6. Always (finally): delete `.npmrc`, kill Verdaccio, remove `<tmp>`.
